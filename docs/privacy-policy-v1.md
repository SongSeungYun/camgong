**캠공 개인정보 처리방침**

캠공(이하 "캠공")은 같은 학교 학생끼리 공동구매를 하도록 돕는 서비스로, 개인이 비영리로 운영합니다. 캠공은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 처리하기 위해 이 처리방침을 둡니다.

**1. 처리 목적**

캠공은 다음 목적으로만 개인정보를 처리합니다.

- 회원 가입: 학교 이메일로 재학생인지 확인하고, 메일 주소로 소속 학교를 정합니다.
- 로그인과 본인 확인: 로그인, 로그인 유지, 비밀번호 재설정, 탈퇴할 때 본인을 확인합니다.
- 공동구매 진행: 공구를 열고 참여하며, 수량과 입금·수령 확인을 기록합니다. 같은 공구의 참여자와 개설자에게 필요한 정보를 보여줍니다.
- 알림: 공구가 완료·실패·취소되면 알려줍니다.
- 부정 이용 방지: 로그인 시도와 메일 발송 횟수를 제한합니다.
- 문의와 고충 처리

**2. 처리하는 개인정보 항목**

| 언제 | 항목 |
|------|------|
| 가입할 때 | 학교 이메일, 표시 이름, 비밀번호(복원할 수 없게 암호화해 저장), 동의 시각·버전 |
| 공구를 열 때 | 제목, 상품명, 설명, 상품 링크, 오픈채팅 링크, 수량·가격·마감 시각 |
| 공구에 참여할 때 | 수량, 개설자가 남기는 입금·수령 확인 여부와 시각 |
| 이용하면서 자동으로 생기는 정보 | 로그인 세션 식별자(쿠키), 가입·탈퇴 시각, 소속 학교(메일 주소에서 정함), 로그인 실패 횟수, 가입 신청·비밀번호 재설정 요청 기록(메일 주소, 발송 시각), 알림 |

- 근거: 가입할 때 받는 동의(제15조 제1항 제1호)와 서비스 이용 계약의 이행(같은 항 제4호).
- 접속 IP 주소와 기기 정보는 따로 저장하지 않습니다.
- 주민등록번호, 전화번호, 계좌번호, 결제 정보는 받지 않습니다. 결제와 입금 안내는 서비스 밖(오픈채팅)에서 합니다. 공구 글에 전화번호나 계좌번호를 적지 마세요.

**3. 다른 이용자에게 보이는 정보**

- 표시 이름은 내가 연 공구와 참여한 공구에 함께 보입니다. 이메일은 누구에게도 보이지 않습니다.
- 내가 참여한 공구의 개설자는 내 수량과 입금·수령 확인 여부를 봅니다.
- 내가 연 공구의 제목·상품명과 학교는 로그인하지 않은 사람에게도 보이고, 설명과 상품 링크는 같은 학교 회원에게 보입니다. 오픈채팅 링크는 공구가 완료되면 참여자에게 보입니다.

이것은 서비스 안에서 공구를 진행하기 위해 보여주는 것이며, 캠공이 개인정보를 다른 회사나 기관에 제공하는 것은 아닙니다. 캠공은 개인정보를 제3자에게 제공하지 않습니다.

## 근거 (2026-11-22 조사, 관제탑 리서치 서브에이전트, 법률 검토 없음)

- 국외 이전: 제28조의8 제1항 제3호 가목(계약 이행을 위한 처리위탁·보관을 처리방침에 공개)과 시행령 제31조 제1항 제2호의 여섯 항목. Google LLC 연락처는 Google 한국 추가 고지(효력 2026-05-13), 데이터센터 국가는 Google 데이터센터 위치 페이지, 삭제 뒤 보관 기간은 Google 데이터 보관 정책(약 2개월, 백업 최대 6개월) 기준.
- 위탁: 제26조 제2항(수탁자와 업무 공개). Vultr 서울 리전은 국외 이전이 아니라고 본다(Vultr는 고객 데이터를 고객이 둔 위치 밖으로 동의 없이 옮기지 않는다고 밝힘, 블로그 "Data Residency with Vultr"). Vultr 자동 백업은 보관 위치를 확인 못 해 쓰지 않는다. PIPC가 이를 명시한 문구는 확인 못 함.
- 구제 기관: 작성지침 예시와 PIPC 자체 처리방침 기준. 대검찰청은 2026-10-02 검찰청 폐지로 뺐다(조사 결과, 확인 못 함).
- 과태료: 처리방침을 정하지 않거나 공개하지 않으면 1천만원 이하(제75조 제4항 제8호).

## 남은 위험과 열린 문제

- **개인 Gmail 계정으로는 위탁 문서(제26조 제1항)와 국외 이전 사전 협의(시행령 제29조의10)를 갖추기 어렵다.** 사용자가 Gmail 유지를 골랐다(2026-11-22). 대안은 위탁 약관이 있는 국내 리전 발송 서비스(예: AWS SES 서울)다.
- 서버는 Vultr 서울로 정했다(2026-11-24 사용자 결정, Azure for Students 가입 거절 뒤). 5번 표의 회사명은 The Constant Company, LLC로 적었다(2026-11-26 사용자 결정). VULTR 상표를 가진 회사라는 것은 Vultr 문서 하단에서 확인했다. 약관 본문은 403으로 막혀 계약 상대인지는 확인 못 함.
- 보호책임자 실명·메일은 2026-11-26 사용자가 줬다. 시행일은 서비스를 여는 날로 하고(2026-11-26 사용자 선택) 그날 채운다. 그 전까지 프론트 `build:release`는 `[시행일]` 때문에 일부러 멈춘다.
- 서버 밖 백업은 운영자 맥으로 매일 내려받는다(2026-11-26 사용자 선택, `specs/014-offsite-backup`). 운영자 본인의 기기라 위탁이 아니라고 본다(확인 못 함). 맥에서도 덤프는 7일, 장부는 8일 기준으로 지우고, 맥은 디스크 암호화(FileVault)를 켠다.
- 문의 메일 30일 정리는 `docs/gmail-cleanup.md`의 스크립트가 맡는다.
