# 개인정보 수집·이용 동의 안내문 (v1 초안, 2026-11-18)

가입 화면(`frontend/src/pages/VerifyPage.tsx`)의 동의 체크박스 위에 펼쳐 볼 수 있게 보여줄 문구다. 버전은 `CONSENT_VERSION = 'v1'`을 그대로 쓴다. 실사용자가 동의한 적이 없어서 올릴 필요가 없다. **문구를 바꾸면 버전을 올린다.** 법률 검토는 받지 않았다(확인 못 함).

배포 전에 `[ ]` 칸을 채운다. 위탁 업체 줄은 배포 대상이 확정되면 맞춘다(지금은 관제탑 추천인 Gmail, AWS 기준).

---

**캠공 개인정보 수집·이용 동의**

캠공은 같은 학교 학생끼리 공동구매를 하기 위해 아래 정보를 받습니다.

| 항목 | 목적 |
|------|------|
| 학교 이메일 | 재학생 확인, 로그인 |
| 표시 이름 | 공구에서 나를 알아보게 하기 |
| 비밀번호(복원할 수 없게 암호화해 저장) | 로그인 |
| 공구 개설·참여 기록(수량, 입금·수령 확인 여부) | 공동구매 진행과 기록 |

- **다른 사용자에게 보이는 정보**: 내 표시 이름은 공구에 함께 보입니다. 내가 참여한 공구의 개설자는 내 수량과 입금·수령 확인 여부도 봅니다. 이메일은 다른 사용자에게 보이지 않습니다.
- **맡기는 곳**: 인증 메일은 Google(Gmail)로 보내고, 서버는 Amazon Web Services(서울 리전)에서 운영합니다.
- **보관 기간**: 탈퇴할 때까지 보관합니다. 탈퇴는 내 활동 화면에서 바로 할 수 있고, 탈퇴하면 이메일·표시 이름·비밀번호를 즉시 지웁니다. 함께한 공구의 수량과 입금·수령 기록은 다른 참여자의 기록을 위해 "탈퇴한 회원"으로 남습니다. 알림은 30일이 지나면 자동으로 지웁니다. 문의: `[운영자 연락처]`
- **돈은 다루지 않습니다**: 결제는 서비스 밖에서 합니다. 캠공은 계좌·결제 정보를 받지 않습니다.
- **동의하지 않을 수 있습니다**: 다만 동의하지 않으면 가입할 수 없습니다.

## 구현 메모 (프론트 세션 몫)

- 위 본문을 체크박스 위에 `<details>`(요약: "자세히 보기") 같은 방식으로 보여준다. 체크박스 라벨 "개인정보 수집·이용에 동의해요."는 그대로 둔다.
- 서버는 동의 시각과 버전만 저장한다(`member.consent_at`, `consent_version`). 본문은 저장하지 않는다.

## 열린 문제 (배포 전에 정할 것)

- **탈퇴**: 익명화와 앱 안 탈퇴 버튼으로 정했다(2026-11-19 사용자 "익명화 ㄱㄱ", "탈퇴는 a로가자"). 스펙은 `specs/010-withdraw/spec.md`에 있다. 구현 전에는 위 보관 기간 문구를 지킬 수 없으므로 010이 머지되기 전에 배포하지 않는다.
- **개인정보 처리방침**은 이 동의문과 별도로 공개해야 할 수 있다(확인 못 함). 필요하면 이 본문을 넓혀 처리방침 페이지로 쓴다.
- 동의 전에 남는 정보가 두 가지 있다. 처리방침을 쓰게 되면 거기서 다룬다.
  - `login_attempt`: 로그인에 실패한 이메일(가입하지 않은 주소 포함)과 실패 횟수. 마지막 시도 뒤 하루가 지나고 잠금이 풀리면 정리 작업이 지운다.
  - `pending_signup`: 가입 신청 이메일. 인증 토큰이 만료되고 7일 뒤, 또는 사용되고 하루 뒤에 지운다.
