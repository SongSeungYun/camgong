# 개인정보 수집·이용 동의 안내문 (v1 초안, 2026-11-18)

가입 화면(`frontend/src/pages/VerifyPage.tsx`)의 동의 체크박스 위에 펼쳐 볼 수 있게 보여줄 문구다. 버전은 `CONSENT_VERSION = 'v1'`을 그대로 쓴다(실사용자가 동의한 적이 없어서 올릴 필요가 없다). **문구를 바꾸면 버전을 올린다.** 법률 검토는 받지 않았다(확인 못 함).

`[운영자 연락처]`는 배포 전에 채운다.

---

**캠공 개인정보 수집·이용 동의**

캠공은 기숙사생끼리 공동구매를 하기 위해 아래 정보를 받습니다.

| 항목 | 목적 |
|------|------|
| 학교 이메일 | 재학생 확인, 로그인 |
| 표시 이름 | 공구에서 나를 알아보게 하기 |
| 비밀번호(복원할 수 없게 암호화해 저장) | 로그인 |
| 공구 개설·참여 기록(수량, 입금·수령 확인 여부) | 공동구매 진행과 기록 |

- **개설자에게 보이는 정보**: 내가 참여한 공구의 개설자는 내 표시 이름, 수량, 입금·수령 확인 여부를 볼 수 있습니다. 이메일은 다른 사용자에게 보이지 않습니다.
- **보관 기간**: 탈퇴할 때까지 보관하고, 탈퇴하면 지체 없이 지웁니다. 알림은 30일이 지나면 자동으로 지웁니다. 탈퇴는 `[운영자 연락처]`로 요청해 주세요.
- **돈은 다루지 않습니다**: 결제는 서비스 밖에서 이뤄지고, 캠공은 계좌·결제 정보를 받지 않습니다.
- **동의하지 않을 수 있습니다**: 다만 동의하지 않으면 가입할 수 없습니다.

---

## 구현 메모 (프론트 세션 몫)

- 위 본문을 체크박스 위 `<details>`(요약: "자세히 보기") 등으로 보여준다. 체크박스 라벨 "개인정보 수집·이용에 동의해요."는 그대로 둔다.
- 서버는 동의 시각과 버전만 저장한다(`member.consent_at`, `consent_version`). 본문 저장은 하지 않는다.
- 탈퇴 기능은 MVP에 없다. 그래서 탈퇴는 운영자 연락으로 받는다고 적었다. 탈퇴 기능을 만들면 이 문구를 고치고 버전을 올린다.
