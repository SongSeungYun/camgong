# 개인정보 수집·이용 동의 안내문 (v1, 2026-11-19 고침)

가입 화면(`frontend/src/pages/VerifyPage.tsx`)의 동의 체크박스 위에 펼쳐 볼 수 있게 보여줄 문구다. 버전은 `CONSENT_VERSION = 'v1'`을 그대로 쓴다. 실사용자가 동의한 적이 없어서 올릴 필요가 없다. **실사용자가 동의한 뒤에는 문구를 바꾸면 버전을 올린다.** 법률 검토는 받지 않았다(확인 못 함).

위탁 업체 줄은 배포 대상이 확정되면 맞춘다(지금은 관제탑 추천인 Gmail, AWS 기준). 문의 연락처는 동의문에 넣지 않는다(2026-11-19 사용자 "운영자 연락처는 넣지마"). 연락처는 개인정보 처리방침에 둔다(아래 열린 문제).

---

**캠공 개인정보 수집·이용 동의**

캠공은 같은 학교 학생끼리 공동구매를 하기 위해 아래 정보를 받습니다.

| 항목 | 목적 |
|------|------|
| 학교 이메일 | 재학생 확인, 로그인, 학교 구분(메일 주소의 학교 부분) |
| 표시 이름 | 공구에서 나를 알아보게 하기 |
| 비밀번호(복원할 수 없게 암호화해 저장) | 로그인 |
| 공구 글(제목, 상품명, 설명, 상품 링크, 오픈채팅 링크)과 참여 기록(수량, 입금·수령 확인 여부) | 공동구매 진행과 기록 |

- **다른 사용자에게 보이는 정보**: 내 표시 이름은 공구에 함께 보입니다. 내가 참여한 공구의 개설자는 내 수량과 입금·수령 확인 여부도 봅니다. 이메일은 다른 사용자에게 보이지 않습니다. 내가 연 공구의 제목·상품명과 학교는 로그인하지 않은 사람에게도 보이고, 설명과 상품 링크는 같은 학교 회원에게 보입니다. 오픈채팅 링크는 공구가 완료되면 참여자에게 보입니다. 공구 글에는 전화번호나 계좌번호를 적지 마세요. 입금 안내는 오픈채팅에서 합니다.
- **맡기는 곳**: 인증 메일은 Google(Gmail)로 보내고, 서버는 Amazon Web Services(서울 리전)에서 운영합니다.
- **보관 기간**: 탈퇴할 때까지 보관합니다. 탈퇴는 내 활동 화면에서 할 수 있습니다. 모집 중이거나 마감 확정을 기다리는 공구가 있으면 탈퇴할 수 없습니다. 모집 중인 공구는 참여를 취소하거나 내가 연 공구를 취소하면 되고, 마감 확정을 기다리는 공구는 확정된 뒤에 할 수 있습니다. 탈퇴하면 이메일·표시 이름·비밀번호, 내 알림, 내가 연 공구의 설명을 바로 지웁니다. 백업과 인증 메일 발송 기록에서는 7일 안에 지워집니다. 다른 참여자의 기록을 지키기 위해 함께한 공구의 수량과 입금·수령 기록, 내가 연 공구의 제목·상품명·상품 링크·오픈채팅 링크, 소속 학교, 가입·탈퇴 시각, 동의 시각·버전은 "탈퇴한 회원"으로 남습니다. 알림은 30일이 지나면 자동으로 지웁니다.
- **돈은 다루지 않습니다**: 결제는 서비스 밖에서 합니다. 캠공은 계좌·결제 정보를 받지 않습니다.
- **동의하지 않을 수 있습니다**: 다만 동의하지 않으면 가입할 수 없습니다.

## 구현 메모 (프론트 세션 몫)

- 위 본문을 체크박스 위에 `<details>`(요약: "자세히 보기") 같은 방식으로 보여준다. 체크박스 라벨 "개인정보 수집·이용에 동의해요."는 그대로 둔다.
- 서버는 동의 시각과 버전만 저장한다(`member.consent_at`, `consent_version`). 본문은 저장하지 않는다.

## 근거 (2026-11-19 재검수)

- 남기는 값의 근거는 개인정보 보호법 제37조 제3항 단서와 제2항 제2호다. 지우면 다른 참여자의 정산 이익을 해칠 수 있다. 남기는 이유는 본문에 적었다(제37조 제4항 통지).
- 공구 설명은 자유 텍스트라 연락처·계좌가 들어갈 수 있고, 완료 공구는 고칠 수 없다. 그래서 탈퇴 때 지운다(2026-11-19 사용자 "탈퇴 때 비우기").
- "7일"은 백업 보관(`deploy/backup.sh`), MySQL binlog(끔), Gmail 보낸편지함 정리 절차(`docs/deploy-checklist.md` 7.1)를 합친 상한이다(2026-11-19 사용자 "7일"). 이 셋이 배포 때 지켜지지 않으면 이 문장은 거짓이 된다.
- 연락처는 수집·이용 동의 고지 사항(제15조 제2항: 목적, 항목, 보유 기간, 거부권)이 아니라서 동의문에서 뺐다.

## 열린 문제 (배포 전에 정할 것)

- **탈퇴**: 010으로 구현했다. 010이 머지되기 전에는 배포하지 않는다.
- **개인정보 처리방침**: 배포 전에 따로 만들어 공개한다(제30조). 보호책임자 연락처로 서비스 Gmail(2.1에서 SMTP용으로 만들 계정)을 적는다(2026-11-19 사용자 선택 "동의문엔 빼고 처리방침엔 서비스 메일"). 비밀번호를 잊은 회원은 학교 메일로 비밀번호를 재설정해 직접 탈퇴한다(2026-11-22, `specs/011-password-reset`). Gmail의 국외 보관 여부(제28조의8)도 여기서 다룬다(확인 못 함).
- 동의 전에 남는 정보가 두 가지 있다. 처리방침에서 다룬다.
  - `login_attempt`: 로그인에 실패한 이메일(가입하지 않은 주소 포함)과 실패 횟수. 마지막 시도 뒤 하루가 지나고 잠금이 풀리면 정리 작업이 지운다.
  - `pending_signup`: 가입 신청 이메일. 인증 토큰이 만료되고 7일 뒤, 또는 사용되고 하루 뒤에 지운다.
