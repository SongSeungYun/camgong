# Quickstart: 화면 검증

> 추천안 기준(사용자 결정 대기). 요청·응답은 [contracts/ui-api-map.md](contracts/ui-api-map.md), 상태는 [data-model.md](data-model.md).

화면이 end-to-end로 동작하는지 확인하는 시나리오다. 먼저 **목(MSW)**으로 돌리고, 백엔드 기능이 구현될 때마다 **같은 시나리오를 실제 백엔드로** 다시 돌려 목이 계약에서 벗어나지 않았는지 확인한다.

## 준비

- Node.js LTS, `frontend/`에서 `npm install`.
- 목으로 실행: `VITE_USE_MOCK=true npm run dev`. 실제 백엔드로: 백엔드를 띄우고 `npm run dev`(Vite 프록시 `/api`).
- 자동 테스트: `npm test`(Vitest), `npm run e2e`(Playwright 360px).
- 확인 폭: 360px(휴대폰), 1280px(데스크톱).

## 실제 백엔드 재확인

백엔드 기능이 끝날 때마다 해당 시나리오(001: 14~20, 003: 1~6·11~12·28, 002: 7~10·13·31, 004: 21~27, 006: 29, 007: 30)를 목 없이 다시 돌린다. 어긋나면 목과 `ui-api-map.md`를 고치거나 계약 변경 요청을 관제탑에 올린다.
